# 📚 המדף שלי — מעקב וחיפוש ספרים

אפליקציית web (React + TypeScript + Vite) לחיפוש ספרים ומעקב אחרי הקריאה שלך.

## תכונות
- **חיפוש ספרים** דרך [Google Books API](https://developers.google.com/books) — לפי כותרת, מחבר או ISBN.
- **מדפים אישיים**: רוצה לקרוא / קורא כרגע / סיימתי.
- **מעקב התקדמות קריאה** (עמוד נוכחי מתוך סך העמודים, באחוזים).
- **דירוג בכוכבים וביקורת אישית** לכל ספר.
- שמירת כל הנתונים בדפדפן (`localStorage`) — ללא צורך בשרת או הרשמה.
- ממשק בעברית, RTL.

## פיתוח

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
